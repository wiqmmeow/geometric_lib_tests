# Лабораторная работа № 4 — Написание Unit-тестов

## Цель работы

Изучить модульное тестирование Python с использованием библиотеки `unittest`.

## Объект тестирования

Функции вычисления площади и периметра круга, прямоугольника, квадрата и треугольника.

## Тесты

В файле `test_shapes.py` реализованы 8 тестов: по одному для площади и периметра каждой фигуры.

## Запуск тестов

Из корневой папки проекта выполните команду:

```bash
python -m unittest test_shapes.py
```

Ожидаемый результат: все 8 тестов проходят успешно.
